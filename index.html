DSH Local Dispatcher

Work with Gmail and Google Calendar in the Local Dispatcher preset of DeepSeek Harness on a Windows PC.

Why it requests Google access

Gmail
Find messages and threads, manage drafts and labels, send email, and move mail to Trash when requested.
Google Calendar
Check availability and create, edit, or remove events when requested.

The desktop integration uses the Google Workspace CLI. The user signs in and approves permissions through Google before the integration can read or change account data.

Where the work runs

Local Dispatcher processes connected-account results with its local model. This website provides information about the integration and its data handling.
