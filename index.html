DSH Local Dispatcher Privacy policy

DSH Local Dispatcher

Read Gmail and Google Calendar in the Local Dispatcher preset of DeepSeek Harness on a Windows PC.

Why it requests Google access

Gmail
Find and summarize messages and threads the user asks about.
Google Calendar
Read calendars and events to answer scheduling and availability questions.

The desktop integration uses the Google Workspace CLI. The initial connection requests read-only access to both services. The user signs in and approves access through Google.

Where the work runs

Local Dispatcher processes connected-account results with its local model. This website provides information about the integration and its data handling.
