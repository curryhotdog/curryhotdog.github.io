DSH Local Dispatcher Privacy policy

Privacy policy

November 11, 2026

This policy applies to the Gmail and Google Calendar integration in DSH Local Dispatcher.

Data access and use

Google asks the user to approve the requested permissions. With the initial read-only permissions, the integration can retrieve Gmail messages, thread content, labels and related metadata, and calendar and event details such as titles, times, and availability. It retrieves Google data to answer the user's requested email or calendar task.

Processing and sharing

The Google Workspace CLI communicates with Google to retrieve the requested data. The Local Dispatcher preset is configured to keep connected-account results with the local Strata model and to delegate only public or synthetic material to cloud workers. The integration uses Google data for the requested features and does not sell it or use it for advertising or model training. This informational website does not handle the desktop sign-in or receive Gmail or Calendar results.

The use of information received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

The CLI keeps its Google authorization locally and protects saved credentials through its local credential storage. DSH can retain requests and tool results in its local session history. Files the user chooses to save remain at their selected locations. To remove those copies, delete the relevant DSH sessions and saved files on the PC.

Use Google Account connections to revoke the integration's access. Use gws auth logout with the Local Dispatcher Google Workspace configuration to remove the CLI's local authorization. Revocation and local file deletion are separate actions.

Questions and changes

For questions, use the support email shown on the Google consent screen. If the integration changes its use of Google data, this policy will be updated and the user will be asked to consent before the new use begins.
